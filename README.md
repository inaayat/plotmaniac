# Plotmaniac

A field guide to publicly reported H3 / Ethan Klein internet lore, set in the Plotmaniac coming-soon palette.

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

The timeline, filters, and relationship web read `data/events.json`, `data/people.json`, and `data/relations.json`. Check that archive with:

```bash
node scripts/test-never-ending-internet-lore.mjs
```
